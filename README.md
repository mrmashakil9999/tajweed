# بوت دليل التجويد

بوت تيليجرام عربي يبحث عن الآية بالنص أو بالمرجع، ويعرض السورة ورقم
الآية وأحكامًا تجويدية أولية وتفسيرًا مختصرًا وتلاوة صوتية واختبارًا سريعًا.

## التشغيل

1. ألغِ أي توكن سبق نشره، وأنشئ توكنًا جديدًا من `@BotFather`.
2. انسخ `.env.example` إلى ملف اسمه `.env`.
3. ضع التوكن الجديد في `.env`.
4. شغّل:

```powershell
python main.py
```

ثبّت الاعتماد مرة واحدة باستخدام `python -m pip install -r requirements.txt`.
يحتاج البوت اتصالًا بالإنترنت، ويُنزّل نص القرآن في أول تشغيل ويحفظه في
`data/quran.json`.

يعالج البوت طلبات التفسير والصوت في الخلفية بالتوازي، ويخزن النتائج التي
سبق طلبها في الذاكرة لتسريع الطلب التالي طوال فترة التشغيل. ويعيد استخدام
اتصال HTTPS نفسه لتقليل زمن الاستجابة لرسائل تيليجرام.
كما يعالج الرسائل وضغطات الأزرار بالتوازي مع استقبال التحديثات الجديدة، حتى لا
يتوقف مستخدم خلف إرسال تفسير طويل أو طلب مستخدم آخر.

## أوامر البوت

- `/start` بدء الاستخدام.
- `/help` تعليمات مختصرة.
- `/random` آية عشوائية.
- `/readers` اختيار قارئ مفضّل.
- البحث بنص مثل `من شر ما خلق`.
- البحث بمرجع مثل `113:2`.
- البحث باسم السورة ورقم الآية مثل `البقرة 255`، مع دعم الأرقام العربية
  والأخطاء الإملائية البسيطة، ثم تأكيد الآية المقترحة من المستخدم.

## القرّاء المتاحون

مشاري العفاسي، محمود خليل الحصري، محمد صديق المنشاوي، عبد الباسط
عبد الصمد، عبد الرحمن السديس، ماهر المعيقلي، علي الحذيفي، محمد جبريل، ومحمد أيوب.
بعد عرض الآية اضغط «استماع» ثم اختر القارئ المطلوب.

يمكن اختيار التفسير الميسّر أو تفسير السعدي أو تفسير الطبري من زر «اختر التفسير»،
كما يتوفر اختبار لأحكام التجويد واختبار لإكمال الكلمة الناقصة من الآية.

## ملاحظات الدقة

- القراءة المستهدفة هي حفص عن عاصم.
- تحليل التجويد آلي تعليمي، وليس فتوى أو بديلًا عن التلقي والمشافهة.
- يلزم تدقيق قواعد التحليل ومخرجاتها مع معلّم تجويد قبل النشر العام.
- مصدر النص والصوت حاليًا هو Al Quran Cloud، ومصدر التفاسير الثلاثة هو Al Furqan؛
  ويُنصح لاحقًا بالحصول على اعتماد Quran Foundation واستخدام محتواها الموثق.
